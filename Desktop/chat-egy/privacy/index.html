سياسة الخصوصية

خصوصيتك مهمة بالنسبة لنا. توضح هذه الصفحة كيف نتعامل مع البيانات داخل ريلز العرب.

1. البيانات التي نجمعها

  • بيانات الحساب الأساسية مثل الاسم واسم المستخدم والبريد الإلكتروني.
  • المحتوى الذي ترفعه مثل الفيديوهات والتعليقات.
  • بيانات التفاعل داخل المنصة مثل الإعجابات والمفضلات والمتابعة.

2. استخدام البيانات

  • تحسين تجربة الاستخدام وتشغيل خصائص المنصة.
  • إظهار المحتوى المناسب وإدارة الحسابات.
  • تعزيز الأمان واكتشاف المخالفات.

3. مشاركة البيانات

لا نقوم ببيع بياناتك الشخصية. قد نشارك بيانات محدودة فقط عند الحاجة القانونية أو التشغيلية.

4. حقوق المستخدم

يمكنك طلب تعديل أو حذف بيانات حسابك عبر صفحة التواصل.
